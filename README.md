# TFG: **Stream Learning con DoME**

Este repositorio contiene el código y los experimentos de mi Trabajo de Fin de Grado (TFG) centrado en el uso de **Stream Learning** combinado con la técnica de **DoME** (Development of Mathematical Expressions). El objetivo de este TFG es evaluar cómo los modelos de regresión simbólica (DoME) pueden adaptarse a **entornos de aprendizaje en flujo**.

## Descripción

El **Stream Learning** es un paradigma de aprendizaje automático donde los modelos se entrenan y evalúan de manera continua sobre datos que llegan en un flujo. Este tipo de aprendizaje es especialmente útil cuando los datos son demasiado grandes para almacenarlos o cuando los datos cambian con el tiempo (drift).

**DoME**, por otro lado, es una técnica de **regresión simbólica** que busca encontrar expresiones matemáticas interpretables que modelen los datos. En este TFG, evaluaremos cómo **DoME** se adapta a los datos en flujo y cómo se compara con otros algoritmos clásicos de aprendizaje automático para *streams*.
